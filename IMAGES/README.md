# Car Price Prediction — Visualizations

This folder contains the key visualizations generated during the **Car Price Prediction Machine Learning Project**. The plots support exploratory data analysis, model evaluation, and interpretation of the machine learning results.

## Included Visualizations

* **Price Distribution** — Shows the distribution of car selling prices and highlights potential skewness and outliers.
* **Correlation Heatmap** — Displays relationships between numerical variables and identifies important predictors.
* **Model Comparison** — Compares the performance of the evaluated regression models using metrics such as MAE, RMSE, and R².
* **Actual vs Predicted Prices** — Evaluates how closely the model's predictions align with observed selling prices.
* **Feature Importance** — Highlights the variables contributing most strongly to the Gradient Boosting model's predictions.

## Purpose

These visualizations provide a visual summary of the dataset, model performance, and predictive drivers, helping translate the machine learning results into interpretable insights.
